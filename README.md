One joke about cats, one line, under 200 characters — written for the
[make.fun competition](https://make.fun/bounty/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).

The entry:

> I asked my cat for emotional support — he sat on my laptop, deleted my work email, and purred. Technically, he removed the source of my stress.

## How it works

`main.py` (Python 3, stdlib only) reads the joke from `entry.txt` next to
it and copies it verbatim to `$MAKEFUN_OUTPUT_DIR/entry.txt` with mode
0644. No network, no secrets, no other files.
